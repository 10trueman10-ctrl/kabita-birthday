KABITA — THE BIRTHDAY EDITION

Your website is in index.html. The photos are in the photos/ folder.

PREVIEW:
- Open index.html in a browser. Keep the photos folder next to it.

PUBLISH WITH GITHUB PAGES:
1. Sign in to https://github.com/ and create a new PUBLIC repository named kabita-birthday.
2. On the repository page, choose Add file > Upload files.
3. Upload index.html, README.txt, and the entire photos folder (with all 10 JPEGs).
4. Commit the upload to the main branch.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose Branch: main and Folder: / (root), then Save.
8. Wait a minute or two. Your website will appear at:
   https://YOUR-USERNAME.github.io/kabita-birthday/

IMPORTANT:
- Keep the photos folder and its filenames unchanged, or the gallery images will break.
- Anyone with the public link can view the site and photos. Only upload photos you are comfortable sharing.
- The Google Fonts connection requires internet; the page still works with fallback fonts if unavailable.
- Edit the text in index.html if you want to personalise the letter further.
